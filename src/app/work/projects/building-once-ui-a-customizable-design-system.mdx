## Overview

Designed and deployed a real-time API monitoring solution to ensure high availability and quick failure detection. By integrating Prometheus, Blackbox Exporter, Alertmanager, and Grafana, the system continuously probes API endpoints, visualizes health metrics, and sends proactive alerts when issues arise.

## Key Features

- API Endpoint Probing: Configured Blackbox Exporter to monitor both public and private APIs for uptime and response time.

- Metrics Collection: Prometheus scrapes probe results and provides a centralized data source for analysis.

- Alerting System: Alertmanager sends instant notifications via email when endpoints become unresponsive.

- Dashboards & Visualization: Grafana dashboards display real-time API health, latency, and uptime trends.

- Local Deployment: Entire setup deployed on a Multipass Ubuntu VM for testing, successfully simulating production-grade monitoring.
## Technologies Used

- Prometheus, Blackbox Exporter, Alertmanager, Grafana, Multipass Ubuntu VM.
## Challenges and Learnings

A key challenge was ensuring secure monitoring of private APIs without exposing sensitive endpoints. Solved this by fine-tuning Blackbox Exporter modules and Prometheus scrape configs. Learned how to tune alert thresholds to avoid false positives while maintaining reliability.

## Outcome

Implemented a lightweight, scalable, and production-ready monitoring solution capable of tracking thousands of APIs. The setup improved incident response by enabling early detection, real-time dashboards, and proactive alerts—leading to higher reliability and observability.
